# OwnVoice

**Tone-aware speech recognition for Mandarin speakers with dysarthria.**

🌐 **Live site:** https://anonymous6623-ownvoice.static.hf.space
🤖 **Model:** https://huggingface.co/anonymous6623/ownvoice-asr
📄 Entry for the 2026 Presidential Hackathon International Track — *Digital
Inclusion in the AI Era*.

## What this is

Dysarthria follows stroke, Parkinson's, ALS, cerebral palsy and head-and-neck
cancer surgery. Speech recognition collapses on it. In Mandarin there is a
second failure the English-language literature does not address: **tone is
lexically contrastive**, so a mistoned syllable is not an accent — it is a
different word. 統一 (tǒng yī, "unify") becomes 同一 (tóng yī, "the same").

This repo contains a dysarthria simulator, a tone-aware metric suite, a
fine-tuned Mandarin ASR model, an API, and the site that presents it.

## Status — read this before citing anything

| component | state |
|---|---|
| Dysarthria simulation | working, acoustically validated |
| Tone metrics (CER / TER / **STER**) | working, regression-tested |
| Stage 1 — dysarthria-robust ASR | **working**, 80.9% → 86.2% intelligibility |
| API (`/health`, `/simulate`, `/transcribe`) | working |
| Website | working, deployed |
| Stage 2 — voice restoration | **not built**; the VC attempt failed and is documented |

**Everything is measured on *simulated* dysarthria.** The model was trained on
perturbations generated by this repo, so part of the gain may be learning to
invert our own simulation. No real patient speech has been used yet. Per
Interspeech 2025 ("Synthetic Dysarthric Speech: A Supplement, Not a Substitute
for Authentic"), that is valid for architecture work and **not** a clinical
claim.

Full numbers, including the negative results, are in [`docs/results.md`](docs/results.md).

## Headline result

Matched evaluation — both models on the *same* held-out speakers, per condition:

| condition | CER base | CER tuned | Δ |
|---|---|---|---|
| clean | 0.1076 | 0.1155 | +0.0078 |
| mild | 0.1605 | 0.1370 | −0.0235 |
| moderate | 0.2074 | 0.1311 | −0.0763 |
| severe | 0.2877 | 0.1683 | **−0.1194** |
| **overall** | 0.1908 | 0.1380 | **−0.0528** |

**Intelligibility 80.9% → 86.2% (−27.7% relative CER).** Gains scale with
severity, which is the clinically correct shape.

**But tone did not improve** (STER −0.0041). Character accuracy rose 27.7%
while tone accuracy stood still. That is the gap this project exists in, and it
is the most important finding here.

## Quickstart

### Website only

```bash
cd site
npm ci
npm run dev          # http://localhost:5173
```

The demo section will report the model server unreachable until you start the
API below. Everything else — the exploded view, the tone-flattening
interaction, all measured figures — is client-side and works standalone.

### API + website

```bash
pip install -r requirements.txt
```

On a CPU-only machine install torch first, or you will pull several GB of
unused CUDA libraries:

```bash
pip install torch torchaudio --index-url https://download.pytorch.org/whl/cpu
```

Then, in two terminals:

```bash
python backend/app.py          # :7860
```

```bash
cd site && npm run dev         # :5173, CORS already allows this origin
```

By default the API loads the fine-tuned model from `runs/asr_v1`. To use the
published one instead:

```bash
set OWNVOICE_MODEL=anonymous6623/ownvoice-asr
```

⚠ If `OWNVOICE_MODEL` equals the baseline model, the demo compares the model
against **itself** — identical transcripts, identical scores, no error. Check
`/health` for `"tuned_is_distinct_from_base": true`.

### Reproduce the results

```bash
cd src
```

Build a corpus (streams Common Voice zh-TW, CC0, and simulates dysarthria):

```bash
python data.py --limit 1000 --out ../data/train
```

Verify the simulation actually degrades speech the way it claims:

```bash
python verify_sim.py --root ../data/train
```

Measure the pre-training baseline:

```bash
python baseline.py --root ../data/train
```

Fine-tune. **One epoch is optimal** — it overfits after that:

```bash
python train_asr.py --root ../data/train --epochs 1
```

Matched before/after evaluation:

```bash
python evaluate.py --root ../data/train --tuned ../runs/asr_v1
```

Metric regression tests:

```bash
python test_metrics.py
```

## Repo layout

```
src/          simulation, metrics, training, evaluation
  dysarthria_sim.py   six perturbations over a pyworld decomposition
  verify_sim.py       acoustic validation, gates on three claims
  metrics.py          CER + TER + STER (alignment-based)
  test_metrics.py     STER regression tests
  data.py             paired corpus builder (openly licensed sources)
  data_real.py        loader for real dysarthric corpora
  baseline.py         pre-training reference, with hallucination detection
  train_asr.py        Whisper fine-tuning, speaker-disjoint splits
  evaluate.py         matched per-condition comparison
  vc.py, eval_vc.py, sweep_vc.py, ablate_vocoder.py
                      voice conversion — a documented NEGATIVE result
  speaker_sim.py      WavLM x-vector speaker identity calibration

backend/      FastAPI: /health, /simulate, /transcribe
site/         React + Vite + TypeScript, three.js, GSAP, Lenis
docs/         results, prior art, dataset access, competition handbook
Dockerfile    single-origin container (site + API)
```

`data/` and `runs/` are gitignored — no datasets or weights are in this repo.

## Contributing

The highest-value open task is **validating on real dysarthric speech**. MDSC
(AISHELL-6B) is CC BY-NC 4.0 Mandarin dysarthric speech from 21 patients — the
only obtainable corpus that can test the tone claim on real people. See
[`docs/datasets.md`](docs/datasets.md).

Do **not** add the unlicensed TORGO/UASpeech re-uploads circulating on dataset
hubs. They are restricted patient medical data redistributed without
authorisation.
