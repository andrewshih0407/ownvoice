# extra index below, forces the CPU wheel deterministically.

# ON A GPU MACHINE, install CUDA torch FIRST and it will be kept:
#
#   pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu124
#   pip install -r requirements.txt
#
# pip will not downgrade an already-satisfied torch, so an existing CUDA
# install survives this file.
